Changing or Cancelling an Order

Changing your address

You can change the delivery address while the order status is processing. Once an order has been dispatched the address cannot be changed, but you may be able to redirect it using the carrier tracking link.

Adding items

Items cannot be added to an existing order. Please place a new order; standard delivery is free over £40.

Cancelling

Orders can be cancelled free of charge before dispatch. Cancelled orders are refunded in full within 3 working days.
